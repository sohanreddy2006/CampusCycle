================================================================================
                    CAMPUSCYCLE - BUILD PLAN & REFERENCE
         Campus Resource Sharing & Exchange Platform (MERN Stack)
================================================================================

TECH STACK
--------------------------------------------------------------------------------
| Layer        | Technology                                    |
|------------- |-----------------------------------------------|
| Frontend     | React + Vite + Tailwind CSS + React Router     |
| Backend      | Node.js + Express.js                           |
| Database     | MongoDB + Mongoose                             |
| Auth         | JWT + bcrypt (university email domain)         |
| File Storage | Cloudinary (free tier) or local uploads        |
| State        | React Context API                              |
| Real-time    | Socket.io (messaging)                          |

DATABASE SCHEMAS (Mongoose)
================================================================================

--- USER ---
{
  name:           String (required),
  email:          String (required, unique, university domain),
  password:       String (hashed, required),
  avatar:         String (URL),
  bio:            String,
  phone:          String,
  verified:       Boolean (default: false),
  role:           Enum ['student', 'moderator', 'admin'] (default: 'student'),
  reputation: {
    rating:           Number (default: 0),
    totalRatings:      Number (default: 0),
    completedExchanges: Number (default: 0),
    listings:          Number (default: 0)
  },
  followedTags:   [ObjectId ref Tag],
  wishlist:       [ObjectId ref Listing],
  isActive:       Boolean (default: true),
  suspendedUntil: Date,
  createdAt:      Date
}

--- DOMAIN ---
{
  name:       String (required),
  slug:       String (required, unique),
  icon:       String,
  categories: [{
    name:   String,
    slug:   String,
    items:  [{ name: String, slug: String, defaultTags: [String] }]
  }]
}

Predefined domains:
1. Academics
2. Projects & Electronics
3. Hostel & Campus Life
4. Sports & Fitness
5. Other Student Resources

--- LISTING ---
{
  owner:          ObjectId ref User (required),
  title:          String (required),
  description:    String (required),
  photos:         [String] (URLs),
  type:           Enum ['sell', 'rent', 'lend', 'donate'] (required),
  price:          Number,
  rentPrice:      Number,
  rentDuration:   String,
  deposit:        Number,
  condition:      Enum ['new', 'like_new', 'good', 'fair', 'poor'],
  availability:   String,
  domain:         ObjectId ref Domain,
  category:       String,
  subcategory:    String,
  tags:           [String],
  status:         Enum ['available', 'reserved', 'sold', 'rented', 'borrowed', 'donated', 'unavailable'],
  location:       String (campus pickup point),
  views:          Number (default: 0),
  reservedBy:     ObjectId ref User,
  reservedUntil:  Date,
  createdAt:      Date,
  updatedAt:      Date
}

--- REQUEST ---
{
  requester:      ObjectId ref User (required),
  title:          String (required),
  description:    String,
  type:           Enum ['buy', 'rent', 'borrow'] (required),
  requiredDate:   Date,
  duration:       String,
  domain:         ObjectId ref Domain,
  category:       String,
  tags:           [String],
  status:         Enum ['active', 'matched', 'fulfilled', 'expired', 'cancelled'],
  matchedListing: ObjectId ref Listing,
  createdAt:      Date
}

--- TAG ---
{
  name:       String (required, unique, lowercase),
  slug:       String (required, unique),
  count:      Number (default: 0),
  followers:  [ObjectId ref User]
}

--- CONVERSATION ---
{
  participants:   [ObjectId ref User] (required, max 2),
  listing:        ObjectId ref Listing,
  lastMessage:    String,
  lastMessageAt:  Date,
  createdAt:      Date
}

--- MESSAGE ---
{
  conversation:   ObjectId ref Conversation (required),
  sender:         ObjectId ref User (required),
  content:        String (required),
  read:           Boolean (default: false),
  reported:       Boolean (default: false),
  reportReason:   String,
  createdAt:      Date
}

--- RESERVATION ---
{
  listing:    ObjectId ref Listing (required),
  user:       ObjectId ref User (required),
  expiresAt:  Date (required),
  status:     Enum ['active', 'expired', 'completed'],
  createdAt:  Date
}

--- RATING ---
{
  from:       ObjectId ref User (required),
  to:         ObjectId ref User (required),
  listing:    ObjectId ref Listing (required),
  score:      Number (1-5, required),
  comment:    String,
  type:       Enum ['seller', 'buyer', 'lender', 'borrower'],
  createdAt:  Date
}

--- REPORT ---
{
  reporter:       ObjectId ref User (required),
  type:           Enum ['listing', 'message', 'user'] (required),
  targetId:       ObjectId (required),
  reason:         Enum ['harassment', 'threatening', 'scam', 'prohibited', 'spam', 'inappropriate', 'other'],
  explanation:    String,
  context:        Object (surrounding messages for message reports),
  status:         Enum ['pending', 'under_review', 'resolved', 'dismissed'],
  moderator:      ObjectId ref User,
  decision:       String,
  action:         Enum ['dismiss', 'warn', 'remove_content', 'restrict', 'temp_suspend', 'perm_suspend'],
  history:        [{
    moderator:  ObjectId ref User,
    action:     String,
    decision:   String,
    reason:     String,
    timestamp:  Date
  }],
  createdAt:      Date
}

--- TICKET ---
{
  user:           ObjectId ref User (required),
  category:       Enum ['transaction', 'account', 'appeal', 'harassment', 'general'],
  description:    String (required),
  attachments:    [String],
  status:         Enum ['open', 'in_review', 'waiting_user', 'waiting_action', 'resolved', 'closed'],
  assignedTo:     ObjectId ref User,
  messages:       [{
    sender:     ObjectId ref User,
    content:    String,
    createdAt:  Date
  }],
  resolution:     String,
  createdAt:      Date
}

--- NOTIFICATION ---
{
  user:       ObjectId ref User (required),
  type:       String (required),
  title:      String (required),
  message:    String (required),
  link:       String,
  read:       Boolean (default: false),
  createdAt:  Date
}

================================================================================
API ROUTES
================================================================================

--- AUTH ---
POST   /api/auth/register          Register new user
POST   /api/auth/login             Login user
GET    /api/auth/me                Get current user (protected)
POST   /api/auth/verify-email      Verify university email

--- USERS ---
GET    /api/users/:id              Get user profile
PUT    /api/users/profile          Update own profile (protected)
GET    /api/users/:id/listings     Get user's listings
GET    /api/users/:id/ratings      Get user's ratings

--- LISTINGS ---
GET    /api/listings               Get all listings (with filters)
GET    /api/listings/:id           Get single listing
POST   /api/listings               Create listing (protected)
PUT    /api/listings/:id           Update listing (protected, owner)
DELETE /api/listings/:id           Delete listing (protected, owner)
PUT    /api/listings/:id/status    Update listing status (protected)
GET    /api/listings/search        Search listings
GET    /api/listings/domain/:slug  Get listings by domain

--- DOMAINS ---
GET    /api/domains                Get all domains
GET    /api/domains/:slug          Get domain with categories
GET    /api/domains/:slug/categories/:cat  Get subcategories/items

--- TAGS ---
GET    /api/tags                   Get popular tags
GET    /api/tags/:slug             Get tag with listings
POST   /api/tags/:id/follow        Follow/unfollow tag (protected)
GET    /api/tags/search/:query     Search tags

--- REQUESTS ---
GET    /api/requests               Get all requests (with filters)
GET    /api/requests/:id           Get single request
POST   /api/requests               Create request (protected)
PUT    /api/requests/:id           Update request (protected, owner)
DELETE /api/requests/:id           Cancel request (protected, owner)

--- MESSAGES ---
GET    /api/conversations                  Get user's conversations (protected)
POST   /api/conversations                  Start conversation (protected)
GET    /api/conversations/:id/messages     Get messages (protected)
POST   /api/conversations/:id/messages     Send message (protected)
PUT    /api/messages/:id/read              Mark as read (protected)

--- RESERVATIONS ---
POST   /api/reservations                   Reserve listing (protected)
GET    /api/reservations                   Get user's reservations (protected)
PUT    /api/reservations/:id/cancel        Cancel reservation (protected)
PUT    /api/reservations/:id/complete      Complete reservation (protected)

--- RATINGS ---
POST   /api/ratings                        Create rating (protected)
GET    /api/ratings/user/:id               Get ratings for user
GET    /api/ratings/listing/:id            Get ratings for listing

--- REPORTS ---
POST   /api/reports                        Create report (protected)
GET    /api/reports                         Get reports queue (moderator)
PUT    /api/reports/:id                     Update report status (moderator)
GET    /api/reports/my                      Get my reports (protected)

--- TICKETS ---
POST   /api/tickets                        Create ticket (protected)
GET    /api/tickets                         Get user's tickets (protected)
GET    /api/tickets/all                     Get all tickets (admin)
PUT    /api/tickets/:id                     Update ticket (moderator)
POST   /api/tickets/:id/messages            Add message to ticket (protected)

--- NOTIFICATIONS ---
GET    /api/notifications                   Get user's notifications (protected)
PUT    /api/notifications/:id/read          Mark notification read (protected)
PUT    /api/notifications/read-all          Mark all read (protected)
GET    /api/notifications/unread-count      Get unread count (protected)

================================================================================
KEY WORKFLOWS
================================================================================

WORKFLOW A: Search & Follow Tag
  Search #coat -> No listing -> Follow #coat -> New listing appears
  -> Match detected -> Notification sent -> Student opens listing

WORKFLOW B: Create Request
  Student specifies item + type + date -> Request stored as Active
  -> New listing matches -> Notification sent -> Connection made

WORKFLOW C: Complete Exchange
  Browse -> Open listing -> Check details -> Chat -> Negotiate
  -> Reserve -> Meet at campus pickup -> Complete -> Rate

WORKFLOW D: Report & Moderation
  User reports -> Select reason + explanation -> Report enters queue
  -> Moderator reviews context -> Decides action -> History recorded

WORKFLOW E: Support Ticket
  User creates ticket -> Selects category -> Describes problem
  -> Attaches evidence -> Moderator investigates -> Resolution recorded
